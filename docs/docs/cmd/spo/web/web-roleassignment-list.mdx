# spo web roleassignment list

Lists all role assignments for a specific web.

## Usage

```sh
m365 spo web roleassignment list [options]
```

## Options

```md definition-list
`-u, --webUrl <webUrl>`
: URL of the site.
```

<Global />

## Examples

List all role assignments of a specific site

```sh
m365 spo web roleassignment list --webUrl "https://contoso.sharepoint.com/sites/Marketing"
```
