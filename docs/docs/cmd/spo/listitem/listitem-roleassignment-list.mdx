# spo listitem roleassignment list

Lists all role assignments of a list item

## Usage

```sh
m365 spo listitem roleassignment list [options]
```

## Options

```md definition-list
`-u, --webUrl <webUrl>`
: URL of the site where the list item is located.

`-i, --listId [listId]`
: ID of the list. Specify either `listId`, `listTitle`, or `listUrl` but not multiple.

`-t, --listTitle [listTitle]`
: Title of the list. Specify either `listId`, `listTitle`, or `listUrl` but not multiple.

`--listUrl [listUrl]`
: Server- or site-relative URL of the list. Specify either `listId`, `listTitle`, or `listUrl` but not multiple.

`--listItemId <listItemId>`
: ID of the list item.
```

<Global />

## Remarks

You can also retrieve the role assignments of a list item together with its properties by using the `--withPermissions` option of the [spo listitem get](./listitem-get.mdx) command.

## Examples

List all role assignments of a list item in a list specified by title

```sh
m365 spo listitem roleassignment list --webUrl "https://contoso.sharepoint.com/sites/Marketing" --listTitle "Branding" --listItemId 125
```

List all role assignments of a list item in a list specified by ID

```sh
m365 spo listitem roleassignment list --webUrl "https://contoso.sharepoint.com/sites/Marketing" --listId a2baa9d6-ef21-4208-8753-342893c4f0d9 --listItemId 125
```

List all role assignments of a list item in a list specified by URL

```sh
m365 spo listitem roleassignment list --webUrl "https://contoso.sharepoint.com/sites/Marketing" --listUrl "/Lists/Branding" --listItemId 125
```
