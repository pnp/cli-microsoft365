# spo report siteversionstorageusage status get

Retrieves the status of a version storage usage report

## Usage

```sh
m365 spo report siteversionstorageusage status get [options]
```

## Options

```md definition-list
`-u, --siteUrl <siteUrl>`
: URL of the site collection to target.

`--fileUrl <fileUrl>`
: Server-relative URL of the file where the report will be stored.
```

<Global />

## Remarks

:::important

While the job is being processed, you can see the report file being gradually populated. Do not update the file during this time. It will cause the job to fail. Check the progress of the report generation to confirm that the report is fully populated and ready to process.

:::

If you wish to cancel an in-progress report generation, you may simply delete the report file.

## Examples

Get the status of a specific version storage usage report.

```sh
m365 spo report siteversionstorageusage status get --siteUrl "https://contoso.sharepoint.com/sites/marketing" --fileUrl "/sites/marketing/Reports/FileUsage.csv"
```
